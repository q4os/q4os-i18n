# Q4OS translations

Please find files for a specific language: "q4os-tools/[languagecode]/[anyfile].po" and translate related '.po' files using 'poedit' application.

This repository holds the translation sources only. Each catalog is compiled and shipped by the Q4OS package it belongs to, and accepted translations are copied there:

| Catalog | Shipped by |
|---|---|
| appsetup2 | q4os-setup |
| calamares-debian | calamares-settings (live media installer) |
| cpuqinfo | q4os-cpuq |
| desktop-profiler | q4os-sw-profiler |
| q4os-base | q4os-base |
| q4os_lookswitcher | lookswitcher-trinity |
| q4os_screenscaler | q4os-screenscaler |
| software-centre | q4os-swcentre |
| um_config, update-manager | q4os-updater |
| welcome-screen | q4os-welcome |
| wificonnect | q4os-wificonnect |
| q4os-shortcuts | written into the menu and desktop entries of the packages that own them |
